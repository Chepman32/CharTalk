# Internal evidence matrix — 15 RuStore promo claims

| # | Claim | Reachable UI | Implementation evidence | Android support | Limits | Confidence |
|---|---|---|---|---|---|---|
| 1 | Four authored replies let the reader choose their own tone | Reader response tray | `RunScreen` renders the resolved decision choices; dialogue engine rejects decisions that do not resolve to exactly four | React Native Android route | Choices are authored, not free text | High |
| 2 | A committed reply changes durable story state and later content | Reader transcript after choice | `commitChoice` calls `applyChoice`, persists event/state/node, and appends authored reaction and destination messages in one repository mutation | SQLite store wraps mutations in an exclusive transaction | Claim stays qualitative; hidden state is not exposed in UI | High |
| 3 | The ending explains the path and consequences | Recap screen | Recap renders ending title, epilogue facts, and key committed decisions | Shared mobile route | Shows up to four key events in the recap summary | High |
| 4 | The branch map avoids unreached-ending spoilers | Branches screen | Only committed answer text is rendered; unknown slots are dots and undiscovered endings remain unnamed silhouettes | Shared mobile route | It does not reveal unvisited answer text | High |
| 5 | A run can branch from an authored saved point | Branches screen | UI offers saved fork points; repository validates the point, replays the prefix, and creates an independent child run | Durable Android repository | Return is available only at authored saved points | High |
| 6 | Bundled stories remain readable offline | Catalog and story detail | Bundled packages load locally; native repository seeds and reads them from SQLite | Native SQLite implementation | Remote discoveries may require an install, but bundled stories do not | High |
| 7 | Active reading resumes from saved progress | Catalog Continue section and reader | Active runs persist node, sequence, transcript, and stable anchor; Continue routes to the exact run | Native SQLite implementation | Exact content build must remain installed or be restored | High |
| 8 | Search and filters shorten story discovery | Catalog and filter sheet | Search covers story title, premise, and character; filters cover genre, tone, duration, status, rating, local availability, and sort | Shared mobile route | Results depend on catalog metadata | High |
| 9 | Warnings appear before sensitive scenes and an authored safe route can bypass them | Story detail | Warning cards precede start; safe-route button starts a run with the selected warning route | Shared mobile route and repository flow | Safe route is shown only where authored | High |
| 10 | Users can hide new catalog stories by content category | Content controls | Category switches update hidden categories; catalog query excludes matching stories while existing runs remain | Shared mobile route | Applies to catalog discovery, not deletion of existing runs | High |
| 11 | Text can scale to 200% while the four choices stay reachable | Text size and reader | 100/150/200 settings; reader choice tray is vertically scrollable and bounded | React Native Android route | It does not promise every screen fits without scrolling | High |
| 12 | Motion and message pacing can be reduced or made instant | Settings and reader | Reduced motion, normal/slow/instant speed, and reveal-immediately all feed the reveal delay calculation | React Native Android route | These affect presentation, not story logic | High |
| 13 | Multiple visual themes support different lighting preferences | Appearance | System, light, dark, warm, and mono radio options apply immediately through the theme provider | React Native Android route | No automatic schedule beyond system preference | High |
| 14 | Optional weekend reminders can be tuned to the reader | Settings notifications | Local notification plan supports story type, weekly/fortnightly/four-week cadence, weekend day, and time; native gateway schedules Android notifications | Expo Notifications Android gateway | Requires user permission and opt-in | High |
| 15 | Local data can be exported or deleted by the user | Settings privacy/storage | JSON export uses native share; delete-all clears local repository data after confirmation | React Native Share and native repository | Export destination is chosen through the Android share sheet | High |

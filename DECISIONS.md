# CharTalk decision register

The entries below convert the PDS's temporary assumptions into accepted implementation defaults for this repository. Product owners can supersede them with a dated entry; code and content migrations must cite the replacement decision.

## Accepted for v1 implementation

| ID    | Decision                                                                                                    | Consequence                                                                                                                                                                                              |
| ----- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OQ-01 | Core catalog is 16+.                                                                                        | No explicit sexual content; high-intensity material requires warnings and safe routes.                                                                                                                   |
| OQ-02 | No 18+ catalog in v1.                                                                                       | Mature taxonomy remains forward-compatible but is not exposed.                                                                                                                                           |
| OQ-03 | Launch shape starts with contemporary drama, mystery, and grounded supernatural stories.                    | Bundled evidence pack uses these genres; launch inventory still requires human editorial approval.                                                                                                       |
| OQ-04 | Lightly customized self-insert protagonist.                                                                 | Player supplies a display name and grammatical addressing profile; no defined avatar or biography.                                                                                                       |
| OQ-05 | System UI uses neutral Russian imperatives and avoids gendered direct address.                              | Copy does not depend on `ты/вы`; character dialogue owns its relationship register.                                                                                                                      |
| OQ-06 | `ё` is written explicitly except for intentional character voice.                                           | Compiler lints common accidental substitutions.                                                                                                                                                          |
| OQ-07 | Relationship numbers stay hidden.                                                                           | Recaps show qualitative change and remembered facts.                                                                                                                                                     |
| OQ-08 | A three-second provisional choice window is enabled before the reaction.                                    | Pending intent is durable; the user can send immediately or choose another reply.                                                                                                                        |
| OQ-09 | Replay unlocks after a chapter.                                                                             | Rewind creates a branch from an authored checkpoint.                                                                                                                                                     |
| OQ-10 | Ten active branches per story; older branches can be archived.                                              | Storage and branch UI enforce the cap without deleting data silently.                                                                                                                                    |
| OQ-11 | Accounts and cloud sync are not required for the first reader release.                                      | Guest-first local play is complete; sync contracts and verifier exist but the UI labels cloud restore as unavailable until a separately approved rollout.                                                |
| OQ-12 | No monetization in the first reader release.                                                                | No paywall, entitlement, premium answer, or store dependency is shipped.                                                                                                                                 |
| OQ-14 | No real-time waits in v1.                                                                                   | All pacing is authored presentation delay, never wall-clock gating.                                                                                                                                      |
| OQ-15 | Bundled launch sample avoids profanity.                                                                     | Future profanity levels require separately authored variants, never runtime masking.                                                                                                                     |
| OQ-16 | Broad contemporary Russian with setting-specific variation.                                                 | No forced slang list or translated syntax.                                                                                                                                                               |
| OQ-17 | Current plus two previous minor content versions are supported.                                             | Package archive and migration tests retain three compatible lines.                                                                                                                                       |
| OQ-18 | iOS 17+ and Android 10/API 29+ are the initial support floor.                                               | Revisit from audience/device evidence before store submission.                                                                                                                                           |
| OQ-20 | SQLCipher is deferred pending threat-model evidence.                                                        | OS encryption and secure token storage are mandatory; progress DB has no auth secrets.                                                                                                                   |
| OQ-21 | Character-voice push notifications are off.                                                                 | Only generic app-branded categories are modeled.                                                                                                                                                         |
| OQ-22 | No cross-character shared state.                                                                            | State paths are scoped by story/run.                                                                                                                                                                     |
| OQ-23 | Original stylized art with documented provenance.                                                           | Generated development portraits are marked as generated and require creative/legal acceptance before store use.                                                                                          |
| OQ-27 | AI-assisted content may be used only as clearly labeled non-production fixture material.                    | It cannot receive native-editor approval or count toward the 300,000-unit GA gate.                                                                                                                       |
| OQ-28 | Build a narrow custom content studio.                                                                       | It owns schema-aware editing, review statuses, simulation, validation, and immutable export—not general document management.                                                                             |
| OQ-29 | Notification delivery is excluded from the first reader release until value and ethics review are complete. | The preference field remains migration-compatible, but the UI does not request system permission or pretend delivery is active. Generic app-branded categories can be enabled in a later signed release. |

## External decisions still required before public operations

- OQ-13: financing/staffing and the date at which the human-approved 300,000-unit GA gate is met.
- OQ-19: identity providers, only if account sync is approved later.
- OQ-24: distribution territories and store/legal review.
- OQ-25: exact analytics, support-bundle, and account retention periods before public collection.
- Production signing-key custody, publisher RBAC, incident rota, and human accessibility/editorial sign-off.

These are release-evidence gates, not hidden TODOs in gameplay code.
